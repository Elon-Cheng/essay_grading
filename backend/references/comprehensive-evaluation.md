# 全文五块评价

属于全文层。只分析本篇实际表现，提炼跨段规律与优先级，不复制词句批注或逐段点评。英文维度名用于分析，不增加 IELTS 分数；仍按高考25分制。

在 `#### 全文综合评价和提升建议` 内，依次使用下列五个独占一行的正文加粗标题。每块按指定顺序输出普通正文子标签，标签后用冒号，不加粗、不另设 Markdown 标题。每项非空、有原文依据，兼顾分析与动作；无明确问题时说明可保留、复核或迁移，不凑错误、亮点或建议。新增事实仅作明确标注的示例，不重写整篇。

## 1. 综合评价

标题：`**综合评价**`

- `Strengths:` 提炼任务、内容、组织或语言的有效之处与具体效果；自然、简洁、准确也有价值，不仅表扬复杂表达。
- `Improvement Suggestions:` 按影响排序给本篇优先修改的位置、原因和方法，区分必要纠正与可选优化。
- `Enhancement Path:` 从本篇水平出发说明先巩固什么、再发展什么，以及进入下一阶段的检查标准，不保证提分。
- `Action Plan:` 落为本次修改、复核、下一篇训练和完成标准，避免重复上一项的抽象方向。

## 2. Task Response｜任务回应

标题：`**Task Response｜任务回应**`

- `Position and Argument Analysis:` 按真实题目检查身份、读者、目的、必答要点、立场与理由。按体裁调整，书信、叙事或方案不强套议论文；无题目说明限制。
- `Evidence and Examples Assessment:` 分析理由、例子、细节的相关性、具体性及支持作用，不强制统计数据、外部引用或固定例子数量。
- `Content and Structure Optimization Suggestions:` 定位本篇需要补充、删减、展开或调整顺序的内容，说明如何更好完成任务，不重复连接词建议。
- `Improvement Suggestions:` 给下一篇任务回应训练和检查标准，与本篇修改区分，如列必答要点、把理由与例子配对。

## 3. Coherence and Cohesion｜连贯与衔接

标题：`**Coherence and Cohesion｜连贯与衔接**`

- `Paragraph Structure:` 检查段落任务、主题句、支撑内容和顺序，不强制段数或模板，未分段时据实说明。
- `Linking Devices:` 结合具体内容检查连接词、指代、关键词复现及替代是否自然准确，不以数量评价衔接。
- `Logical Flow:` 分析观点、理由、例子和结论的推进，定位真实跳跃、重复或关系不明；隐含但清楚的关系也认可。
- `Specific Improvements:` 定位相邻句或段落，说明必要的重排、解释、指代调整或删重复；无问题时给保留与复核方向。
- `Practical Examples:` 给与建议一致的英文局部例子，并用英文说明关系；原句成立时明确为可选优化或迁移示例。

## 4. Lexical Resource｜词汇

标题：`**Lexical Resource｜词汇**`。以下中文标签是内部解析协议，点评正文仍为英文。

- `词汇范围：` 分析主题词汇、变化、重复和可积累表达，不以生僻复杂程度衡量范围。
- `精确度：` 结合真实表达检查词义、搭配与语境，区分明确错误和可选优化。
- `学术风格：` 按体裁、读者与目的分析书面语体及正式程度，不把高中书信或叙事强改成学术论文。
- `改进方向：` 定位优先用词或搭配问题，给修改或积累动作；无问题时建议保留、复用和复核。
- `举个例子：` 引用真实表达，给保留原意的英文局部改法或迁移例子，用英文说明价值，不强造错误或虚构引用。

## 5. Grammatical Range and Accuracy｜语法

标题：`**Grammatical Range and Accuracy｜语法**`

- `Sentence Variety:` 说明实际简单句、并列句、复合句和长短句变化及作用，不把长句多等同于好。
- `Advanced Structures:` 引用实际从句、非谓语、让步、强调或平行结构，分析准确性与作用；未使用则据实说明并给相称的可选训练。
- `Error Patterns:` 从明确观察的错误归纳规律，个别问题不说成反复错误；无错误时据实说明。
- `Specific Corrections:` 给真实错误的最小英文改法与依据；无必要纠错时说明可保留，优化或复核例子明确其性质。
- `Progressive Improvement:` 给从准确性到有效句式变化的渐进训练和检查动作，不强制高级结构或固定数量。

五块后仅输出总分与 A–E 表，按评分及输出规范执行。不输出旧五角度诊断、旧四块总评、高分词或额外词块卡片。词汇积累由独立通道按对应 Skill 生成，不属于报告 JSON 或这五块，也不添加到 Markdown 或 Word。
