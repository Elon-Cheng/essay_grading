# Error 与 Suggestion 的边界

Error 必须同时满足：原文存在可明确观察的语言错误；改动实质修复该错误。依据完整句子和上下文解释，给保留原意的最小改法，放回句中复核语法、搭配、逻辑主语、语体和空格。

- 语法：检查主谓一致、时态、冠词／限定词、单复数、从句、非谓语、句界及平行结构。说明实际机制，不只给新句。
- 词汇：区分词义、词形、拼写、固定搭配和语境误用；混淆词须解释本句适用性。
- 理解：优先纠正影响理解的真实词句错误；不能仅因复杂、长或不够高级就判错。
- 风格：原句成立时，换同义词、语气调整、精简或更自然的表达为 Suggestion，使用可选语气。原文与改法相同不能判 Error。
- 内容／逻辑：任务遗漏、论据不足、推断过强、信息重复或衔接欠顺通过建议说明，不冒充语言 Error，不直接增加学生未写的事实。

例如 enable the expert know 缺 to，修复有明确依据；pressure 可以作动词，Parents always pressure students 不能仅因偏好 put pressure on 就判错。Nowadays 不限定只能搭配某一种时态；between 与 among 不仅按对象数量判断。词汇罕见、语法正确、衔接词多都不能替代上下文判断。

优先处理影响任务和理解的问题，再处理准确性、衔接及有价值的优化。没有明确证据时不造错；同一问题不重复解释。
