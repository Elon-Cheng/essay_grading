# 反馈语言与切换

- 新批改的点评、原因解释、学习建议和全文各项正文使用英文。题目、学生原文、引用及英文改法保留原文字面内容。
- 独立近义词拓展数据的 meaning_zh 使用简短中文语境释义，由批改阶段直接生成；original 与 synonyms 保留英文，不进入点评翻译槽位。
- 页面操作界面保持中文，专业标题沿用现有结构，不进行整页翻译。每张词句卡、每段反馈、每个全文块独立提供点击翻译／查看英文。
- 批改任务完成前预生成并保存同一份反馈的中文译文，预览同时携带中英文。前端点击直接切换，不调用翻译模型；译文未完整就绪时明确状态并保留英文。
- 中文只翻译点评，不重新批改、不新增建议，不改变原文、英文示例、quote、correction、编号、偏移、类型、标题、总分或 A–E 标红。
- Markdown 内部中文标题、词汇子标签、总分行和表格字段是解析协议，不随正文翻译。格式说明正文也用英文，如 Keep the original text.。
- 历史译文按实际点评内容匹配，不覆盖原报告或独立批注，不让新点评复用旧内容译文。默认英文不因参考文件中的中文教学说明而改变。
