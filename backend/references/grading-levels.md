# 五层点评与职责

先通读题目和全文，再由局部到整体分析；五层是观察层级，不是五套重复批注。

| 层级 | 检查重点 | 呈现位置 |
|---|---|---|
| 单词 | 拼写、词义、词形及用词准确性 | 结合短语／句子语境解释，不独立逐词建卡 |
| 短语 | 地道搭配、固定结构、语体、过渡表达 | 与句子层共同组成词句批改单元 |
| 句子 | 句法、句意、指代、局部逻辑与前后承接 | 与短语层共同组成词句批改单元 |
| 段落 | 本段任务、内容展开、观点与理由／例子、段内组织 | 独立逐段反馈 |
| 全文 | 任务覆盖、篇章结构、整体语言与训练优先级 | 五块全文评价及总分 |

- 当前批改单元是短语／句子联合单元。一条批注可综合单词、搭配、句法和局部逻辑，按主要评价对象标 phrase 或 sentence；同一处问题不拆成两层重复点评。
- 阅读完整上下文，引用最小必要连续原文；单词词形错误可只修改一个词，但解释须结合其搭配或句法关系。
- 段落点评讲本段内容与展开，不逐条重述词句纠错；报告的语言提升保留语言解释供 Word 使用。全文评价提炼跨段规律与优先级，不复制逐段反馈。
- 逐段点评对象是有实际内容的开头段、正文各段和结尾段。独立称呼、问候、落款敬语、署名、日期及题目说明属于格式段，不单独生成段落点评或问题建议，保留原文并使用格式说明。不能仅因段落很短就排除；表达总结、请求、期待或行动建议的简短结尾仍需点评。
- 12–18条只计算词句单元，不计算段落反馈或全文模块。五层点评与全文五个分析模块是不同概念。
