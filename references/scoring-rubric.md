# 上海高考英语作文评分速查

本文件统一任务与质量判断、25分制评分锚点；层级分工、点评语气和格式由各自规范负责。

## 一、总分与评分维度

上海高考英语写作满分 **25分**。先进行整体定档，再用以下三项分值校准最终分数，不要只按语法错误数量机械扣分。

| 维度 | 分值 | 主要观察点 |
|---|---:|---|
| Content 内容 | 10 | 是否审题准确、要点完整、内容充实、观点清楚、细节相关、任务目的达成 |
| Language 语言 | 10 | 语法、词汇、搭配、句式、准确性、自然度、表达能力和语体 |
| Organization 组织 | 5 | 段落结构、逻辑推进、衔接、连贯性和整体篇章组织 |
| **总分** | **25** | |

## 二、五档标准

| 档位 | 分数 | 定档依据 |
|---|---:|---|
| 第五档 | 21–25 | 切题且充分完成任务；内容充实并有有效展开；语言总体准确自然，能恰当使用较丰富词汇和多样句式；结构清晰，衔接自然，交际目的达成良好。 |
| 第四档 | 16–20 | 较好完成任务；主要内容完整，但个别细节或论证略显不足；语言基本准确，有少量语法、搭配或用词问题；整体连贯，段落组织较清楚。 |
| 第三档 | 11–15 | 基本完成任务；能表达主要内容，但展开有限，部分要点不清或不充分；存在一定语言问题，但总体不妨碍理解；结构基本完整，逻辑和衔接较简单。 |
| 第二档 | 6–10 | 未能充分完成任务；有明显内容缺失、偏题、论述不足或重复；语言错误较多，部分影响理解；句式和词汇较单一，组织和衔接较弱。 |
| 第一档 | 1–5 | 内容严重不足、明显偏题或难以形成有效表达；语言错误频繁并明显影响理解；结构混乱，难以达成写作目的。 |
| 零分 | 0 | 空白、完全无关、照抄无关内容，或几乎无法判断为有效英语作文。 |

高难词汇、背诵句式或复杂结构本身不构成高分理由。学生尝试复杂表达时，只要错误轻微且意思清楚，不应因复杂度而过度扣分。

## 三、分项评分锚点

### Content / 10

| 分数 | 评分锚点 |
|---:|---|
| 9–10 | 主题明确，完整回应任务，信息、理由或细节充实且有效，内容切题并有较充分展开。 |
| 7–8 | 主要要求均有回应，内容较充实，但个别部分展开不足或细节略显薄弱。 |
| 5–6 | 基本回应任务，但内容发展有限，部分要点不清、缺失、空泛或重复。 |
| 3–4 | 明显遗漏主要内容，部分内容与主题关系较弱，任务完成度偏低。 |
| 0–2 | 严重偏题、内容极少，或基本没有完成写作任务。 |

重点检查：是否理解题目、是否覆盖全部要求、中心是否清楚、理由和例子是否真正支持观点、是否存在万能套话或无关内容。

### Language / 10

| 分数 | 评分锚点 |
|---:|---|
| 9–10 | 语言表达能力强；语法和词汇总体准确自然；搭配恰当，句式有变化，少量错误不影响整体质量。 |
| 7–8 | 语言较准确；有少量语法、搭配或用词问题；能使用一定的复杂结构，错误通常不影响理解。 |
| 5–6 | 基本能够表达意思，但错误较明显；词汇和句式较普通，部分表达不自然。 |
| 3–4 | 错误较多，词汇和句式受限，部分句子理解困难。 |
| 0–2 | 错误频繁且严重影响理解，难以形成连续有效的英语表达。 |

重点检查：时态、主谓一致、从句、冠词、介词、非谓语、句界、搭配、词形、拼写、标点、中式英语和语体。

### Organization / 5

| 分数 | 评分锚点 |
|---:|---|
| 5 | 结构完整清晰，段落功能明确，逻辑推进自然，句间和段间衔接有效，全文统一连贯。 |
| 4 | 整体结构清楚，主要逻辑合理，偶有衔接生硬或段落展开不均衡。 |
| 3 | 基本有结构，但逻辑推进简单，部分句子或段落衔接不足。 |
| 2 | 组织较松散，段落功能不清，有明显跳跃、重复或顺序问题。 |
| 0–1 | 缺乏有效组织，内容零散或结构混乱。 |

## 四、定档与扣分原则

1. 先通读全文，判断任务完成度、语言质量和篇章组织，再确定大致档位。
2. 再分别给 Content、Language、Organization 分数，并检查三项合计是否与档位表现一致。
3. 严重偏题、关键要求缺失或体裁错误时，即使语言流畅，也不应定为高档。
4. 语法错误只有在影响准确性、清晰度或交际效果时才重点扣分；不要把每个可优化表达都当作错误。
5. 复杂句越多不等于分数越高。准确、切题、清楚、自然优先。
6. 模板化表达若没有服务当前题目，应降低内容和内容展开评价。
7. 字数按题目要求判断。无明确字数要求时按本服务250–300词训练范围提示，不声称为官方要求；明显过短影响任务完成，过长导致重复或偏题时影响内容和组织。
8. 没有原题时，语言和组织可以正常评价，但任务完成度和内容评价必须标注为“暂定”。

## 五、评分展示

分项得分仅用于内部校准；成稿只显示25分制总分或合理区间及 A–E 参考表，三列各标红本文对应档位。具体格式见 [output-format.md](output-format.md)。

## 任务与质量检查

依据真实题目、身份、读者、目的和体裁判断；非议论文不强制立场或反驳。理由、例子和细节须相关且充分，模板、重复和无关信息不代替展开。不强制四段式，不按连接词数量判断连贯。优先遵循原题字数；无明确要求时采用本服务250–300词训练范围，正文不含称呼和署名，不冒充官方统一限制。
