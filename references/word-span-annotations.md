# 短语／句子联合批改单元

层级分工见 [grading-levels.md](grading-levels.md)。网页或离线批改都使用本标准；网页格式由 web-annotations-prompt.md 规定。

## 定位与层级

- 先读完整句子及相邻上下文，再引用足以解释点评的最小连续原文。quote 必须逐字匹配，不能先纠错再引用，不圈整段。
- 搭配、固定结构或过渡短语主要标 phrase；句法、句意、逻辑主语、指代或句间关系主要标 sentence，不按词数机械分类。句子层也可只圈必要句段。
- 单词问题结合短语／句子解释。同一处问题只形成一条综合批注，不因观察角度不同拆分、重复或交叠。
- correction 仅替换 quote 的范围，放回完整句子复核；额外上下文写在 comment。例如 We meets every Friday. 引用 We meets，改为 We meet。

## 类型

| 类型 | 要求 |
|---|---|
| Good Point | 按 highlight-expression-principles.md 判断原文亮点，不把教师新建议当作学生表达 |
| Suggestion | 原表达可成立但有具体优化价值，解释原因及最小可选改法，不强改原文 |
| Error | 按 error-taxonomy.md 的双重条件给明确依据与实质纠正；纯删除可用空 correction |
| 不评价 | 无明确问题或学习价值时保留原文，不因没有错误就表扬 |

## 逻辑与衔接

- 短语检查连接表达的递进、转折、因果、让步和举例关系是否符合实际语境，以及指代和关键词承接是否清楚。
- 句子检查与前后句的承接、观点与理由／例子的对应、因果和推断依据，以及重复、跳跃或必要解释缺失。合理隐含的关系不判错，不机械增加连接词。
- 点评说明具体上下文、影响和改进方法，不能只说加强逻辑。纯逻辑优化为 Suggestion；有效逻辑表达仍须按亮点标准判断 Good Point。

## 数量与优先级

每篇合计以12–18条为目标，三类点评及两个层级共同计数，不设各类配额。先检查各正文段，优先真实错误、重要逻辑／衔接优化，再选地道亮点。超过18个候选时保留影响和教学价值最高的18条，其他必要语言问题在报告语言提升中说明。

有依据、独立且不重复的候选不足12条时据实输出，允许更少或空结果；不制造问题、拆分、重复、泛泛表扬或降低判定标准来凑数。
