# Shanghai Gaokao English Writing Rubric

Use this rubric for **上海高考英语（Shanghai Gaokao English）作文评分、逐句批改、语言提升、逻辑分析与修改建议**。

This rubric is grading-focused. It is designed for a student-provided essay rather than for generating an unrelated model essay.

## Task Mode

Use **Writing grading mode** when the user provides their own English essay and asks for any of the following:

- 作文评分
- 作文批改
- 逐句批改
- 语法修改
- 词汇修改
- 语言提升
- 段落点评
- 逻辑分析
- 润色
- 扣分原因
- 提分建议
- 学习建议

If the original writing prompt is available, score task completion and content against the prompt.

If the original prompt is not available, grade language, organization, and the visible content provisionally, and clearly mark prompt-dependent judgments as provisional.

Do not automatically replace the student's essay with a completely different model essay. Revision should preserve the student's original meaning, structure, and level as much as possible while improving accuracy, clarity, logic, and expression.

---

## Score Total

Shanghai Gaokao English writing is graded on a **25-point scale**.

Use three primary dimensions:

| Dimension | Points | Core focus |
|---|---:|---|
| Content | 10 | 审题、任务完成度、内容充实度、观点与细节、相关性 |
| Language | 10 | 语法、词汇、搭配、句式、准确性、地道性、表达能力 |
| Organization | 5 | 段落结构、逻辑推进、衔接、连贯性、整体篇章组织 |
| **Total** | **25** | |

The final score should reflect the overall quality of the essay rather than a mechanical sum of isolated errors.

---

## Recommended Length

For this skill, use 250–300 words as the Shanghai Gaokao exam-writing target. Count the English body only, excluding the salutation and signature. Report the actual count in “审题情况”; if it is below 250 or above 300, explicitly remind the student that exam writing should contain 250–300 words.

Word count is part of task completion, not an independent reason to ignore the actual quality of the writing.

---

## Band Standards

Use the following five-band framework as the main scoring anchor.

| Band | Score | Overall performance |
|---|---:|---|
| 第五档 | 21–25 | 很好地完成写作任务。内容充实、切题且有较充分展开；语言表达能力强，语法与词汇总体准确，允许因尝试较复杂表达出现少量错误；结构清晰，衔接自然，能够有效达成交际目的。 |
| 第四档 | 16–20 | 较好地完成写作任务。主要内容完整，个别细节或论证略显不足；语言基本准确，能够使用一定的复杂结构和较丰富词汇；文章整体连贯，段落组织较清楚。 |
| 第三档 | 11–15 | 基本完成写作任务。能够表达主要内容，但展开有限或部分内容不够清楚；存在一定语法、词汇或搭配问题，但大体不妨碍理解；结构基本完整，逻辑和衔接较简单。 |
| 第二档 | 6–10 | 未能充分完成写作任务。存在明显内容缺失、偏题、论述不足或重复；语言错误较多，部分影响理解；句式和词汇较单一；段落组织、逻辑推进或衔接较弱。 |
| 第一档 | 1–5 | 内容严重不足、明显偏题或难以形成有效表达；语言错误频繁并明显影响理解；结构混乱，难以达成写作目的。 |
| 零分 | 0 | 空白、完全无关、照抄无关内容，或几乎无法判断为有效英文作文。 |

Do not award a high band merely because the essay contains difficult vocabulary or memorized sentence patterns.

Do not heavily penalize a student merely for attempting complex structures if the errors are minor and meaning remains clear.

## Dimension Scoring Guide

### Content — 10 points

Evaluate:

- whether the student correctly understands the task;
- whether all major requirements in the prompt are addressed;
- whether the central idea is clear;
- whether supporting details are relevant and sufficient;
- whether examples, reasons, explanations, or comparisons actually support the point;
- whether the response contains empty template language, repetition, or irrelevant material;
- whether the writing achieves the intended communicative purpose.

Suggested anchors:

| Score | Description |
|---:|---|
| 9–10 | 内容充实，主题突出，完整回应任务要求；信息、理由或细节充分且有效。 |
| 7–8 | 内容较充实，主要要求均有回应，但个别部分展开不足或略显笼统。 |
| 5–6 | 基本回应任务，但内容发展有限，部分要点不清楚、缺失或较空泛。 |
| 3–4 | 主要内容存在明显遗漏，部分内容与主题关系弱，任务完成度较低。 |
| 0–2 | 严重偏题、内容极少，或基本没有完成写作任务。 |

### Language — 10 points

Evaluate:

- grammar accuracy;
- sentence control;
- tense and voice;
- subject-verb agreement;
- clauses and sentence boundaries;
- articles and prepositions;
- word choice;
- collocation;
- spelling;
- punctuation;
- Chinglish;
- vocabulary range;
- sentence variety;
- register and appropriateness;
- clarity and naturalness.

Suggested anchors:

| Score | Description |
|---:|---|
| 9–10 | 语言表达能力强；语法和词汇总体准确，表达自然；能够恰当使用较丰富词汇和多样句式，少量错误不影响整体质量。 |
| 7–8 | 语言较准确；存在少量语法、搭配或用词问题；能够使用一定复杂结构，错误通常不影响理解。 |
| 5–6 | 基本能够表达意思，但错误较明显；句式与词汇较普通，部分表达不够自然。 |
| 3–4 | 语言错误较多，词汇和句型受限，部分句子理解困难。 |
| 0–2 | 错误频繁且严重影响理解，难以形成连续有效的英文表达。 |

### Organization — 5 points

Evaluate:

- paragraph division;
- function of each paragraph;
- internal paragraph logic;
- progression of ideas;
- relationship between claims and support;
- transitions between sentences and paragraphs;
- coherence;
- introduction and conclusion when appropriate;
- whether information is ordered naturally;
- whether the article feels like a unified whole.

Suggested anchors:

| Score | Description |
|---:|---|
| 5 | 结构清晰完整；段落功能明确；逻辑推进自然；句间、段间衔接有效。 |
| 4 | 整体结构清楚；主要逻辑合理；偶有衔接生硬或部分段落展开不均衡。 |
| 3 | 基本有结构，但逻辑推进较简单；部分句子或段落衔接不足。 |
| 2 | 结构较松散；段落功能不清；存在明显逻辑跳跃、重复或顺序问题。 |
| 0–1 | 缺乏有效组织，内容零散或结构混乱。 |

---

## Scoring Principles

1. **先整体定档，再进行分项评分。**
   Do not determine the total score solely by counting grammar mistakes.

2. **内容、语言、组织结构必须结合起来判断。**
   A grammatically accurate essay with empty content should not receive a top score.

3. **复杂表达不是越多越好。**
   Reward complexity only when it is appropriate, understandable, and reasonably controlled.

4. **模板化语言必须服务于当前题目。**
   Generic memorized expressions that do not contribute to the task should not receive extra credit.

5. **关注交际效果。**
   Judge whether a real reader can clearly understand the student's purpose, position, reasoning, and key information.

6. **保留学生原意。**
   Corrections and revisions should improve the student's own essay rather than replace it with an unrelated high-level composition.

# Writing Grading Mode

## Required Behavior

When grading an essay:

1. Read the writing prompt first when it is available.
2. Identify the task type, audience, communicative purpose, required content, and expected stance.
3. Count the student's words.
4. Read the entire essay before correcting individual sentences.
5. Make an initial holistic judgment and provisional band placement.
6. Score:
   - Content /10
   - Language /10
   - Organization /5
7. Analyze every paragraph.
8. Correct the essay sentence by sentence.
9. Separate **real errors** from **optional stylistic improvements**.
10. Explain important vocabulary or collocation upgrades instead of only giving replacement words.
11. Give sentence-level or local examples only when they clarify a difficult correction; do not provide a full revised essay.
12. Identify the main score-limiting problems and connect them to specific paragraphs.
13. Give concise, targeted training advice without repeating earlier comments.

Classification must be evidence-based. Use “错误” only for a demonstrable grammar, meaning, collocation, factual, or contextual violation; use “可选优化” for improvements in naturalness, specificity, concision, or register. Do not turn tendencies such as tense choice after `Nowadays` or preferences between `between` and `among` into unconditional rules.

When replacing a complex sentence, explain each high-impact problem before giving the local example. Keep content diagnosis separate from invented supporting detail: optional ideas may be shown as examples but must not be inserted into the student's original argument.

## Output Format

The authoritative output structure is [output-format.md](output-format.md). Use its three-part structure. The detailed headings below are retained only as grading considerations; do not reproduce them as separate output chapters when they would repeat paragraph feedback.

### 一、作文评分定位

Include:

- 考试：上海高考英语
- 题目/任务类型
- 满分：25
- 考场词数要求：250–300词
- 实际字数
- Content：__/10
- Language：__/10
- Organization：__/5
- **总分：__/25**
- 档位
- 一句话诊断

The one-sentence diagnosis should identify the single most important reason the essay is currently at this score.

---

### 二、题目要求梳理

When the original prompt is available, identify:

1. **写作身份**
2. **目标读者**
3. **交际目的**
4. **必须完成的内容点**
5. **需要表达的观点、理由、建议或信息**
6. **适合的语体与语气**

Then state whether the student's essay has covered each major requirement.

If the prompt is missing, explicitly say:

> 未提供原题，因此“内容/任务完成度”的判断为暂定评分。

Do not invent unseen prompt requirements.

---

### 三、总体评价

Give a concise overall diagnosis before detailed corrections.

Cover:

- strongest aspect of the essay;
- biggest weakness;
- whether the current score is mainly limited by content, language, organization, or a combination;
- what improvement would produce the largest score gain.

Avoid vague praise such as “整体不错” without explaining why.

---

### 四、分项评分

Use this table:

| 维度 | 满分 | 得分 | 当前表现 | 主要扣分原因 | 提分方向 |
|---|---:|---:|---|---|---|
| Content | 10 | | | | |
| Language | 10 | | | | |
| Organization | 5 | | | | |

The explanations must be tied to evidence in the student's essay.

---

### 五、段落点评

Analyze **every paragraph separately**.

For each paragraph, include:

#### 第 X 段

**1. 本段内容**

Explain what the paragraph is saying.

**2. 本段作用**

Explain the paragraph's role in the full essay, for example:

- introduction / background
- stating a position
- reason 1
- reason 2
- example
- comparison
- counterargument
- recommendation
- conclusion

**3. 段内逻辑**

Check:

- whether the ideas follow a clear order;
- whether claims are supported;
- whether there are logical jumps;
- whether reasons actually support the main point;
- whether examples are specific enough.

**4. 与前后段衔接**

Explain whether the transition is natural and whether the paragraph advances the whole essay.

**5. 改进建议**

Give concrete content or logic improvements.

Do not focus only on grammar in this section.

---

### 六、段内语言批改

Place each correction under its original paragraph. Do not number every sentence or repeat correct sentences in a separate table. Preserve the complete original paragraph and mark only meaningful errors or useful optimizations.

---

### 七、语言提升

Place each item under the relevant paragraph and use four fields:

| 原表达 | 问题性质 | 建议表达 | 中文原因及可迁移用法 |
|---|---|---|---|

“问题性质” must identify **错误** or **可选优化** and may add an error tag. Explain why the recommendation fits this sentence and state a reusable grammar, collocation, or register rule. After replacement, reread the full sentence to ensure it remains grammatical, faithful to the original meaning, and natural.

---

### 八、逻辑与结构提升

Identify the most important organization problems in the whole essay.

Check for:

- unclear thesis;
- weak topic sentences;
- unsupported claims;
- repetition;
- logical jumps;
- weak paragraph progression;
- examples disconnected from arguments;
- abrupt conclusion;
- overuse of mechanical linking words.

Give concrete restructuring advice.

When useful, provide a simple paragraph map such as:

- P1: 明确情境 + 表明立场
- P2: 理由一 + 具体解释/例子
- P3: 理由二 + 具体解释/例子
- P4: 回扣任务 + 得出结论

Do not force a fixed four-paragraph structure when the task does not need it.

---

### 九、局部修改示例

Do not provide a full revised essay. For a complex sentence, one local example may be given when it helps the student understand structure, logic, or register. Explain the reason and keep it attached to the relevant paragraph. Do not combine local examples into a rewritten essay.

---

### 十、本篇作文最需要解决的问题

List the **top 2–3 score-limiting problems** only.

For each problem explain:

1. what the problem is;
2. where it appears in this essay;
3. why it lowers the Shanghai Gaokao score;
4. what the student should do next time.

Prioritize high-impact issues instead of listing every minor mistake.

---

### 十一、长期学习与积累建议

Do not limit the advice to this single essay.

Give targeted study advice based on recurring weaknesses visible in the writing.

Possible areas include:

- 多阅读英文外刊或高质量英语文章，观察地道表达；
- 建立高频搭配而不是只背孤立单词；
- 做近义词和词义辨析积累；
- 建立自己的错误句档案；
- 训练复合句，但优先保证准确；
- 学习 topic sentence + explanation + example 的段落展开方式；
- 练习论点与论据之间的逻辑关系；
- 积累不同写作任务中的功能表达；
- 写完后进行 grammar / vocabulary / logic 三轮自检。

Advice must be connected to the student's actual problems whenever possible.

---

## Error Priority

When time or output length is limited, prioritize corrections in this order:

1. Task misunderstanding / off-topic content
2. Missing required content
3. Logic that prevents the argument from working
4. Grammar errors that affect understanding
5. Wrong word choice or collocation
6. Unnatural Chinglish
7. Sentence-level clarity
8. Cohesion
9. Style improvement
10. Minor punctuation or cosmetic issues

---

## Teacher Feedback Style

Feedback should be:

- specific;
- evidence-based;
- concise but sufficiently explanatory;
- constructive;
- suitable for a Shanghai high-school student;
- focused on how to improve the next piece of writing.

Avoid:

- empty praise;
- excessive rewriting;
- unexplained vocabulary replacement;
- treating every stylistic preference as an error;
- rewarding difficult vocabulary purely for being difficult;
- comments such as “逻辑不好” without identifying the exact logical gap.

The student should understand not only **what to change**, but also **why it should be changed and how to avoid the same problem next time**.
